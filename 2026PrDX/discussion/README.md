# 2026PrDX Discussion

このフォルダは、リチウムイオン二次電池のプロセス開発および試作環境DXに関する
議論、仮説整理、提案、ケーススタディ案をまとめるためのディスカッションベースです。

## 目的
- Pythonで何ができるかの切り口を整理する
- 小規模モデルを素早く作り、ケーススタディを回せる状態を作る
- 将来的な試作環境DXの要件定義・PoCテーマ選定につなげる

## 想定する進め方
1. 現場課題・業務プロセス・データの整理
2. Python活用テーマの棚卸し
3. 小規模モデルの優先順位付け
4. ケーススタディ実施
5. 効果検証と次フェーズ計画
