# 研究開発部マネジメント支援ツール Ver0.0.1 現在の進捗状況

## 1. 概要
研究開発部のマネジメントを支援するためのMVP（最小実行可能製品）として、Ver0.0.1を構築しました。
単独動作するWebアプリケーション形式（Streamlit）で、データの永続化にはSQLiteを使用しています。

## 2. 実装済み機能
要件定義書（Specnote.md）のPhase 1に基づき、以下の機能を実装しました。

### 2.1 ダッシュボード（全体概況）
- 進行中のテーマ数、遅延マイルストーン数、未解決課題数、実験登録数を一目で把握可能。
- 各テーマの平均進捗率をマイルストーンから自動計算して一覧表示。

### 2.2 研究テーマ一覧管理
- テーマ名、責任者、ステータス、開始日、目標完了日などの登録・編集。
- スプレッドシート形式（Excelライク）での直接編集と保存が可能。

### 2.3 進捗・マイルストーン管理
- 各テーマに紐づくマイルストーンの予定日・実績日・進捗率の管理。
- テーマ別のフィルタリング機能。

### 2.4 課題・リスク管理
- 発生した課題やリスクの登録、重要度、期限、対応方針の記録。

### 2.5 実験結果・ナレッジ管理
- 日々の実験条件、結果、考察、タグ付けの記録。

## 3. 技術構成
- **言語**: Python
- **フレームワーク**: Streamlit (Web UI)
- **データベース**: SQLite (rd_management.db)
- **データ操作**: Pandas
