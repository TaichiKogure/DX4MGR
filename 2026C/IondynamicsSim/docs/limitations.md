# 制限事項

## モデルの前提
- 本シミュレータは PyBaMM の DFN (Doyle-Fuller-Newman) モデルを計算エンジンとして使用しています。
- DFNモデルは1次元の物理モデルであり、粒子配置の可視化はあくまで「空間分布の直感的な理解」を目的とした擬似的なものです。

## 粒子配置
- 粒子配置ジェネレータは簡易的なランダム/格子配置を行っており、実際の電極構造（パッキング密度や粒度分布の詳細な統計）を厳密に再現したものではありません。

## 抵抗内訳
- 抵抗成分の分解は PyBaMM の出力変数から抽出していますが、モデルの設定やバージョンによって完全な電圧整合性が保証されない場合があります（相対的な比較を優先してください）。
