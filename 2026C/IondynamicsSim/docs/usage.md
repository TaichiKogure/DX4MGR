# 用語解説

## イオン輸送抵抗 (Ionic Transport Resistance)
電解液中をリチウムイオンが移動する際の抵抗。電解液の導電率や空孔率、曲路率に依存します。

## 固体内拡散 (Solid Diffusion)
活物質粒子内をリチウムイオンが拡散するプロセス。拡散係数が低いと粒子表面と内部で濃度勾配が生じ、抵抗（過電圧）となります。

## 反応過電圧 (Reaction Overpotential)
電極表面での電荷移動反応に伴う電圧降下。バトラー・ボルマー式などで記述されます。

## オーム損失 (Ohmic Loss)
電子（電極体）やイオン（電解液）の電気伝導に伴う純粋な抵抗損失。
