# Phase 3 理論・計算モデル解説書

## 対象物理
Phase 3 では、リチウムイオン二次電池正極の 2D 断面構造における**電解液中のイオン輸送**を対象としています。

## 採用方程式

### 1. 電解液濃度の拡散方程式
電解液中のリチウムイオン濃度 $c_e$ の時間発展は、以下の拡散方程式で記述されます。
$$\frac{\partial (\epsilon c_e)}{\partial t} = \nabla \cdot (D_{eff} \nabla c_e) + S$$
- $\epsilon$: 局所空隙率（Phase 2 の相マップから取得。孔内は 1、粒子内は 0）
- $D_{eff}$: 実効拡散係数。本モデルでは $D_{eff} = D_{bulk} \times \epsilon$ と近似しています。
- $S$: ソース項。活物質界面ピクセルにおいて、電流密度に応じたイオンの供給・消費が発生します。

### 2. 電解液ポテンシャル分布
電解液内の電位分布 $\phi_e$ は、以下の支配方程式に従います。
$$\nabla \cdot (\kappa_{eff} \nabla \phi_e) = S_{cur}$$
- $\kappa_{eff}$: 実効イオン伝導率。
- $S_{cur}$: 電流ソース項。界面ピクセルでの反応電流の出入りを表します。

## 境界条件

- **セパレータ側 (z=0)**:
    - 濃度: 一定（Dirichlet）または一定流束（Neumann）
    - 電位: 基準電位 (0V)
- **集電体側 (z=Thickness)**:
    - 濃度: 不透過（Zero Flux）
    - 電位: 絶縁（Zero Flux）
- **面内方向 (x=0, x=Width)**:
    - 周期境界（Periodic）または対称境界（Symmetric）を選択可能。

## 主要な指標 (KPI) の定義

### 1. 見かけ輸送抵抗 (Apparent Transport Resistance)
定常状態のポテンシャル分布から、以下の式で算出します。
$$R_{app} = \frac{|\bar{\phi}_{e, CC} - \bar{\phi}_{e, Sep}|}{I_{applied}}$$
ここで、$\bar{\phi}$ は各面での平均電位、$I$ は印加電流密度です。構造が複雑になり、屈曲度が高くなるほど、この抵抗値は増大します。

### 2. 局所枯渇率 (Local Depletion Rate)
電解液濃度が初期濃度の 10% 以下に低下した空隙領域の面積割合です。
$$Rate_{dep} = \frac{\text{Area}(c_e < 0.1 c_0)}{\text{Area}(\text{pore})}$$
この値が上昇し始める時間は「枯渇開始時刻」として、厚膜電極の限界性能を評価する重要な指標となります。

## モデルの限界と拡張方針
- **固相内拡散の省略**: 現在は活物質内部のリチウム拡散を考慮していません。次段階で 2D 粒子内拡散モデルを追加予定です。
- **線形反応近似**: 界面での電荷移動反応（Butler-Volmer 等）は簡易化されており、局所的な過電圧への依存は次段階の課題です。
- **定数物性**: $D_{bulk}$ や $\kappa_{bulk}$ は濃度依存性を持たない定数として扱っています。
