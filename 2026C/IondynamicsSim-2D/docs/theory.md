# IondynamicsSim 技術解説書

本ドキュメントでは、IondynamicsSimの物理モデル、計算ロジック、およびシステム構造について詳細に解説します。

## 1. 物理モデル: DFN (Doyle-Fuller-Newman) モデル

IondynamicsSimは、リチウムイオン電池の電気化学挙動を記述するために、標準的な**DFNモデル**（P2Dモデルとも呼ばれる）を採用しています。計算エンジンにはオープンソースの [PyBaMM](https://www.pybamm.org/) を使用しています。

### モデルの基本構造
DFNモデルは、以下の物理現象を考慮した1次元＋粒子内1次元のモデルです。
- **正極・負極内の電子伝導**: オームの法則
- **電解液内のイオン輸送**: 拡散方程式およびオームの法則（マクスウェル・ステファン拡散を基礎とする）
- **活物質粒子内のリチウム拡散**: フィックの拡散方程式
- **電極反応（界面反応）**: バトラー・ボルマー式

### 厚み方向解析の重要性
厚膜電極（High-loading electrode）では、電解液内のリチウムイオン輸送がボトルネックとなりやすく、セパレータ側と集電体側で反応の不均一が生じます。本ツールはこの「厚み方向の不均一性」を可視化・定量化することに特化しています。

## 2. PyBaMMの活用

本ツールでは、PyBaMMの以下の機能を活用しています。

- **`pybamm.lithium_ion.DFN()`**: 基本モデルの定義。
- **`pybamm.ParameterValues`**: 物性値や構造パラメータの管理。既存のパラメータセット（デフォルトは "Chen2020"）をベースに、ユーザーが指定した厚み、空隙率、導電率などを動的に上書きします。
- **`pybamm.Experiment`**: 充放電サイクルの定義（例: "Discharge at 1C until 2.5V"）。
- **`pybamm.Simulation`**: モデル、パラメータ、実験を統合した計算実行。
- **`sol["Variable Name"].entries`**: 計算結果からの物理量（濃度分布、電位分布、過電圧など）の抽出。

## 3. 追加KPIの定義と算出ロジック

Phase 1で追加されたKPIは、厚膜化による悪化を比較可能にするための指標です。

### Δc_e (Electrolyte Concentration Difference)
- **定義**: $\Delta c_e = c_{e, \text{separator}} - c_{e, \text{collector}}$
- **目的**: 放電時にセパレータから供給されるイオンが集電体側まで届いているかを判定。

### Max Concentration Gradient
- **定義**: $\max |\partial c_e / \partial x|$
- **目的**: 最も輸送負荷が高い場所を特定。

### Effective Ionic Resistance Index (見かけの輸送抵抗指標)
- **定義**: $Index = \Delta c_e / \text{C-rate}$
- **目的**: 濃度差を負荷（電流）で正規化した指標。厚みや空隙率の変化に対する感度が高い。

### Depletion Onset Time (電解液枯渇開始時刻)
- **定義**: $\min(c_e) < c_{\text{threshold}}$ となる最小の時刻。
- **閾値**: デフォルトは初期濃度の 10% (0.1) または絶対値 0.1 mol/m³。
- **目的**: 輸送限界による動作停止のリスクを定量化。

### Ce Ratio
- **定義**: $c_{e, \text{separator}} / c_{e, \text{collector}}$
- **目的**: 濃度の不均一性を無次元量で評価。

## 4. 粒子配置の投影 (擬似2D可視化)

DFNモデル自体は1次元（厚み方向のみ）ですが、IondynamicsSimではその結果を2Dの粒子配置図に投影する機能を備えています。

- **ロジック**: 厚み方向座標 $x$ における値を、その $x$ 座標付近に配置された粒子に割り当てます。
- **用途**: 実際の電極断面のような視覚的な理解を助けるためのデモンストレーション機能。

## 5. システム構造

- `config.py`: YAML設定ファイルの読み込みとバリデーション。
- `simulate.py`: PyBaMMを用いた計算実行のコア。
- `postprocess.py`: KPIの算出とデータ保存。
- `visualize.py` / `animate.py`: プロットおよびアニメーション生成。
- `gui.py`: 全機能を統合するユーザーインターフェース。
- `cli.py`: コマンドラインからの実行制御。
