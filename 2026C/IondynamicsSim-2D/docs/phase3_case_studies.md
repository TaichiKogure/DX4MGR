# Phase 3 ケーススタディ例

2D 輸送ソルバを用いた、電極設計への示唆を得るための解析例を紹介します。

## 1. 電極厚みの影響
- **条件**: 厚み 60, 100, 150 um の比較。
- **期待される結果**: 厚みが増すほど集電体側へのパスが長くなり、定常状態での見かけ抵抗が増大します。また、放電中の集電体近傍での濃度枯渇が早期に発生することが確認できます。
- **設計への示唆**: 求められる C レートに対して、どの厚みまでなら枯渇を防げるかの閾値を特定できます。

## 2. 活物質粒径の影響
- **条件**: 平均粒径 5 um と 15 um の比較（空隙率は同一）。
- **期待される結果**: 大粒子系では粒子間の隙間（Pore path）が広くなりますが、パスの数が少なくなります。2D シミュレーションにより、局所的な「通り道の狭まり」が輸送抵抗に与える影響を可視化できます。
- **設計への示唆**: 粒径分布（単峰 vs 双峰）が曲路率（Tortuosity）をどう改善するかを定量化できます。

## 3. カレンダー圧縮の影響
- **条件**: 圧縮率 1.0 (未圧縮) と 0.8 (20% 圧縮) の比較。
- **期待される結果**: 圧縮により粒子が厚み方向に押し潰され、空隙が狭くなります。特に厚み方向の連通性が低下し、輸送抵抗が急増する様子が観察されます。
- **設計への示唆**: 過度なプレスがイオン輸送を阻害し、出力性能を低下させるリスクを評価できます。

## 4. 面内不均一性の影響
- **条件**: 均一な粒子配置と、意図的にムラ（Cluster）を作った配置の比較。
- **期待される結果**: 粒子が密集している領域で局所的な濃度枯渇が先行し、それが全体の電圧低下にどう波及するかを解析できます。
- **設計への示唆**: スラリー塗工時の分散性が電池性能のバラツキに与える影響をシミュレーションで裏付けできます。
