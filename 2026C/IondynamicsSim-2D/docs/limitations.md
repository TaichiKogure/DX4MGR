# 制限事項と今後の展望

## モデルの前提
- 本シミュレータは PyBaMM の DFN (Doyle-Fuller-Newman) モデルを計算エンジンとして使用しています。
- DFNモデルは厚み方向の1次元物理モデルであり、粒子配置の可視化はあくまで「空間分布の直感的な理解」を目的とした擬似的なものです。

## 粒子配置の扱い
- 現在の可視化用粒子配置ジェネレータは簡易的なランダム/格子配置を行っており、実際の電極構造（パッキング密度や粒度分布の詳細な統計）を厳密に再現したものではありません。
- Phase 1では、粒子ごとの反応不均一性の厳密な計算（2D/3D構造解析）はスコープ外としています。

## 抵抗内訳の精度
- 抵抗成分の分解は PyBaMM の出力変数から抽出していますが、モデルの設定やバージョンによって完全な電圧整合性が保証されない場合があります。絶対値よりも、条件間での相対的な比較を優先して利用してください。

## 枯渇判定
- `depletion_onset_time` は、電解液濃度の最小値が 0.1 mol/m^3 を下回った時刻として定義されています。

## 今後の展望 (Phase 2以降)
- **2D高次構造の実装**: 実際の電極断面画像や生成構造に基づいた、粒子レベルでの電流分布解析。
- **物理抵抗への洗練**: 現在の "index" を、より厳密な過電圧分解に基づいた物理抵抗値へと変換。
- **ユーザーインターフェースの強化**: 複数ケースの自動スイープ設定のGUI化。
