# Plan 7: 高度R&D意思決定シミュレーション基盤 (全面改良版)

## 概要
Plan 7は、Plan 6をベースに「ライブモニタリング」「シナリオ比較」「設定のポータビリティ」を強化したR&D意思決定支援シミュレーターです。
リチウムイオン電池のプロセス開発等における、技術成熟度、リソース制約、組織間通信の影響を動的にシミュレーションし、最適な投資判断を支援します。

## 主な新機能

### 1. ライブモニタリング (リアルタイムグラフ更新)
シミュレーションの実行進捗に合わせて、KPI、技術成熟度、仕掛品(WIP)のグラフがリアルタイムに描画されます。長期間のシミュレーションにおいて、挙動の変化を即座に視認可能です。

### 2. シナリオ比較モード
「Scenario A」と「Scenario B」の2つの設定セットを同時に管理し、並行してシミュレーションを実行、結果を左右に並べて比較できます。
エンジニア数や実験戦略の変更が、最終的な利益や開発期間に与える影響を直感的に把握できます。

### 3. 設定ファイルのインポート/エクスポート
GUIで微調整した20種類以上のパラメータをJSONファイルとして保存・読み込み可能です。
特定のケーススタディ設定をチームで共有したり、以前の設定を瞬時に復元したりできます。

## 実行方法
以下のコマンドでGUIダッシュボードを起動します。
```bash
python gui_sim.py
```

## ディレクトリ構成
- `core/`: シミュレーションエンジンおよびロジック
- `configs/`: デフォルト設定ファイル (JSON, CSV)
- `analysis/`: 可視化・統計分析モジュール
- `reports/`: 実行結果の保存先
- `runner/`: バッチ実行等のユーティリティ
