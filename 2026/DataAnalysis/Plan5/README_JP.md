# Plan 5: 実データ・デジタルツイン連携（データ駆動アプローチ）

このプランでは、シミュレーションのパラメータを理論値ではなく、過去の実際の開発ログ（Jira, ELN等）から推定・反映する「デジタルツイン」的なアプローチをモデル化しています。

## 追加された主要機能

### 1. 実測ログからのキャリブレーション（Calibration from Logs）
過去のプロジェクトデータを読み込み、チームごとの実力値（スキルやエラー率）を自動設定します。
- `configs/past_logs.csv` に記録された「過去の遅延」「エラー率」「手戻り回数」を読み込み、シミュレーション上の `Team.skill` や通信特性に反映します。
- これにより、特定の過去プロジェクト（例：PROJ_B）の状況をベースとした再現シミュレーションが可能になります。

### 2. ベイズ更新の高度化（Advanced Update Logic）
（本モデルでは簡易化していますが）実験データそのものを取り込み、将来の不確実性を予測するロジックの土台を構築しています。

### 3. What-if解析と投資ROIシミュレーション
特定のチームへの投資（ツール導入によるエラー率低減、トレーニングによるスキルアップ）が、最終的なプロジェクト期間やコスト（統合日数）にどう影響するかを、実データに基づいたベースラインと比較できます。

## シミュレーションの実行
`Plan5/` ディレクトリ内で以下のコマンドを実行してください。
```bash
python3 run_sim.py
```

## 観測ポイント
- `DigitalTwin_PROJ_B` シナリオでは、過去ログの `error_rate` が高かった Prototype チームのスキルが低く設定されるため、標準的なシミュレーション（Standard_Sim）よりも `operational_failures` が増える様子が確認できます。
- `HighInvestment` シナリオ（理想的な投資を行った場合）と比較することで、現状のボトルネックを解消した場合の潜在的な改善幅（ROI）を定量化できます。
- プロジェクト開始前の「現実的なスケジュール予測」ツールとしての活用が期待されます。
