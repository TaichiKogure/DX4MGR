# GUI機能統合および `run_sim.py` 停止・削除プラン

## 1. 目的
シミュレーションの実行環境を `gui_sim.py` に集約し、ユーザビリティの向上とコードメンテナンスの効率化を図ります。

## 2. 現在の状況
- **gui_sim.py (v2.0)**: タブ形式の詳細設定、非同期実行、DOE一括実行、詳細レポート出力機能を統合済み。
- **run_sim.py**: CLIベースの実行スクリプト。動的なパラメータ調整が難しく、GUIと機能が重複している。

## 3. 統合・移行状況

### ステップ 1: `run_sim.py` の非推奨化 (完了)
- `run_sim.py` を実行した際、GUIの利用を促す警告メッセージを表示し、実行を停止するように修正済み。
- README等のドキュメントからCLI主体の説明を削除し、GUI推奨へと書き換え完了。

### ステップ 2: 機能の完全移行 (完了)
- パラメータ設定タブの実装により、CLIで行っていた詳細設定をすべてGUIで再現。
- `ScenarioManager` のバッチ実行機能を GUI に統合し、乱数シードを変えながらの連続実行（DOE）を可能に。
- 統合グラフエリアの実装により、可視化機能も完全にGUIへ統合。

### ステップ 3: `run_sim.py` および関連CLIスクリプトの削除 (2026/03/20 予定)
- `run_sim.py`, `run_viz_demo.py`, `test_refactoring.py` などのスタンドアロン実行ファイルは、現在メンテナンス期間として残しているが、次回のリリースで物理削除を行う。

## 4. 最終的なディレクトリ構成 (予定)
```text
DX4MGR/
├── gui_sim.py          # 唯一の実行エントリポイント
├── core/               # シミュレーションエンジン
├── analysis/           # 可視化・分析ロジック
├── configs/            # 設定ファイル・ログ
├── docs/               # ドキュメント
├── reports/            # 出力レポート
└── runner/             # シナリオ実行アダプタ
```

## 5. 実行スケジュール
- **2026/03/14**: `run_sim.py` への警告実装および移行ドキュメント作成、およびGUIの可視化機能（スクロールエリア、統合ダッシュボード）の拡充（完了）。
- **2026/03/15**: ユーザフィードバックに基づき、GUIの微調整。
- **2026/03/20**: `run_sim.py` の物理削除。
