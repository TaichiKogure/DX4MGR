# Plan 6: Hybrid R&D Decision Simulation Model (Integrated Plan 5x & Ver 14)

このプランは、Plan 5x（技術動態・組織・スキル・通信・デジタルツイン）と Ver 14（離散事象シミュレーション・ゲート承認・リソース制約・リワーク）を高度に統合した、R&Dマネジメント向けの次世代意思決定シミュレーションモデルです。

## 統合された主要機能

### 1. ハイブリッド・シミュレーションエンジン (Plan 6 Hybrid)
- **DES (Discrete Event Simulation)**: Ver 14の離散事象エンジンをベースに、リソース（エンジニア数）制約やDR（デザインレビュー）の周期的な開催をモデル化。
- **多段プロセスフロー**: Research（基礎研究）、Prototype（試作）、Mass Production（量産準備）の3フェーズを標準実装。各フェーズを通過するために特定の技術閾値（不確実性や成熟度）を要求。
- **技術動態更新**: 各Job（プロジェクト）がWorkGateを通過する際、Plan 5xのロジックに基づいて技術成熟度（Maturity）が向上し、不確実性（Uncertainty）が減少。フェーズごとに最適な技術要素選択戦略を適用。
- **戦略的選択**: 実験対象を「不確実性が最大のもの」や「成熟度が最低のもの」から優先的に割り当てる戦略を選択可能。

### 2. 多層的な承認プロセスとリワーク (Ver 14由来)
- **DRゲート**: 周期的な開催と承認者（Senior等）のキャパシティ・品質を考慮。
- **リワークループ**: 承認失敗時の再試行（不確実性の再燃）と、知識減衰（Decay）による手戻りコストを算出。
- **コスト算出**: DR開催ごとのコストを累積KPIとして保持。

### 3. 組織・エージェント・デジタルツイン (Plan 5x由来)
- **学習・スキル**: エージェントが実験を重ねることでスキルが向上。
- **組織間通信**: チーム間の情報の欠落・歪みをシミュレート。技術の暗黙知度（Tacitness）が高いほど、通信による情報劣化が深刻化するロジックを搭載。
- **デジタルツイン**: `past_logs.csv` から過去の実績値を読み込み、シミュレーション上の能力値をキャリブレーション。

## 実行方法

### 1. インタラクティブ・ダッシュボード (GUI)
Plan 6の全パラメータをGUI上で調整し、リアルタイムに経営KPIと技術成熟度を確認できます。
```bash
python3 gui_sim.py
```
- **入力**: シミュレーション日数、DR周期、実験戦略、通信品質などを左パネルで設定。
- **ダッシュボード**: 累計Gain、完了ジョブ数、DRコスト、および各技術要素の成熟度/不確実性をグラフ表示。
- **出力**: `reports/plan6_results.csv` に実行結果が自動保存されます。

### 2. バッチ実行 (run_sim.py)
設定ファイルに基づき複数シナリオを一括実行します。
```bash
python3 run_sim.py
```

## 主要ディレクトリ構成
- `core/`: 統合シミュレーションコア（Hybrid Engine, Gates, Entities, etc.）
- `configs/`: 設定ファイル（`simulation_params.csv`, `past_logs.csv`）
- `reports/`: 実行結果（CSV, PNG）
- `analysis/`: Ver 14由来のメトリクス計算ロジック
- `runner/`: フロー構築用アダプター

## モデルの示唆
Plan 6では、「リソース（エンジニア）を増やして実験回数を稼ぐ」ことと、「DRゲートを厳格に運用して品質を保つ」こと、さらに「組織間の通信を円滑にして手戻りを防ぐ」ことのトレードオフを定量的に評価することが可能です。
