# Plan 1: エージェントの詳細度向上（ミクロ・視点の強化）

このプランでは、従来の「チーム単位」のモデルを分解し、チームに所属する「個人エージェント」の行動と能力をモデル化しています。

## 追加された主要機能

### 1. 個人エージェント（Agentクラス）
各チームに複数の個人エージェントが配属されます。
- **スキル（Skill）**: 0.0〜1.0の値で、情報の劣化（欠落・誤解）を抑える能力に影響します。
- **学習効果（Learning Effect）**: タスク（実験、解析、依頼）をこなすごとにスキルが向上します。
- **経験値（Experience Count）**: 担当したタスクの累計数。

### 2. 学習曲線（Learning Curve）
エージェントが経験を積むほど、情報の伝達精度が向上し、実験の成功率や情報取得効率（protocol_adherence）が改善されます。
```python
# 学習ロジックの例
self.skill = min(1.0, self.skill + self.learning_rate * (1 - self.skill))
```

### 3. 担当の入れ替わり（Turnover / 知識の流出）
一定の確率でエージェントがチームを離れ、新しい未熟なエージェントと交代します。
- これにより、長期的なプロジェクトにおいて「チームとしての熟練度」がリセットされるリスクを表現できます。
- 暗黙知度（tacitness）が高い要素を扱っている最中にベテランが抜けると、不確実性の低下が停滞します。

## シミュレーションの実行
`Plan1/` ディレクトリ内で以下のコマンドを実行してください。
```bash
python3 run_sim.py
```

## 観測ポイント
- エージェントの学習により、シミュレーション後半にかけて「運用的失敗」が減少する傾向が見られます。
- 頻繁に入れ替わりが発生する設定（`handle_turnover`の確率を上げる）にすると、いつまでも組織としての学びが蓄積されず、DR到達までの日数が延びることが確認できます。
