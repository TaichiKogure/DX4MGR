# 試作設備DXダッシュボード (スモールスケール版)

`MemoPSM.md` で挙げたMVP3本を、1枚のHTMLダッシュボードに集約した最小プロトタイプです。
電池R&Dの試作設備について「更新すべき設備」「研究を遅らせている工程」「投資候補」を
定量的に可視化し、設備投資の意思決定・上位報告を支援します。

## ダッシュボード構成

| ブロック | 内容 | 対応MVP |
|---|---|---|
| サマリカード | 更新推奨・故障リスク・安全対応・ボトルネックの件数 | 全体 |
| 1. 設備投資優先順位 | 更新優先度スコアの横棒ランキング | MVP3 |
| 2. 工程別ボトルネック | 工程別 負荷率 / 平均待ち日数のグラフ | MVP2 |
| 3. 試作設備台帳 | 全設備のスコア付き一覧表 | MVP1 |
| 4. 研究テーマ×設備マップ | テーマと使用/不足設備の対応表 | 補助 |
| 5. 投資候補ランキング | 不足設備を制約度順に列挙 | MVP3 |

## 使い方

```bash
cd "2026/Prototyping Section Mgr/psm_dashboard"
python3 build_dashboard.py
```

- 追加ライブラリのインストールは不要です（Python標準ライブラリのみ）。
- 実行すると `reports/dashboard.html` が生成されます。ブラウザで開いてください。
- グラフ描画には Plotly.js を CDN から読み込むため、初回表示時のみネット接続が必要です。

### オプション

```bash
python3 build_dashboard.py --data <CSVフォルダ> --out <出力HTMLパス>
```

## データ (data/)

CSVを書き換えて再実行すれば、ダッシュボードが更新されます。

- `equipment.csv` … 設備台帳（老朽化度・稼働率・故障頻度・貢献度・ボトルネック度・安全リスクは1〜5評価）
- `process_load.csv` … 工程別の月間依頼件数・処理能力・待ち日数
- `theme_map.csv` … 研究テーマと使用設備・不足設備の対応

## 更新優先度スコア

`MemoPSM.md` のスコア式に準拠（5点満点換算）。

```
更新優先度スコア =
    研究テーマ貢献度 × 0.25
  + ボトルネック度   × 0.25
  + 老朽化度         × 0.20
  + 故障頻度         × 0.15
  + 安全リスク       × 0.15
```

- スコア ≥ 4.0 → 優先度「高」、≥ 3.0 → 「中」、それ未満 → 「低」
- 負荷率 = 月間依頼件数 ÷ 月間処理能力。100%超でボトルネック、85%以上で逼迫と判定。
